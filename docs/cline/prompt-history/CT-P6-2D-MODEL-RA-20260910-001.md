### IMPORTANT

The Product Owner has clarified the following foundational product model:

> From the beginning, CarbonTally was designed so that Organizations, Consultants, CarbonTally, and Manual Processing Entities can all participate in processing PDF and CSV/Excel data, using either automatic or manual processing where authorized and applicable.

Examples include:

* Organization uploads CSV/Excel → CarbonTally automatically maps data to emission factors.
* If automatic CSV/Excel mapping cannot resolve data → Organization can manually map/correct it.
* Organization uploads PDF → automatic extraction and mapping is attempted.
* If automatic PDF extraction/mapping fails → Organization can manually correct/extract/map the data.
* Consultants can participate in equivalent automatic/manual processing workflows where authorized.
* CarbonTally internal personnel can process data.
* Manual Processing Entities can process data.
* "Manual" is not synonymous with "Consultant" or "Processing Entity."
* Automatic vs manual processing is a separate dimension from who performs processing.

**Do not treat this clarification as a new product requirement or architectural change. Treat it as a statement of the original/foundational CarbonTally model that must be verified against the repository.**
