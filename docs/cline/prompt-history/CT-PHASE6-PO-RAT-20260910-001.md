# 2. AUTHORITATIVE PROCESSING MODEL

The following model is now authoritative and MUST be preserved.

## Actors

CarbonTally has four principal processing actors:

* Organisation
* Consultant
* CarbonTally Internal
* Processing Entity

A system/automatic worker may perform machine processing.

## Processing mode

Processing mode is independent of actor:

* Automatic
* Manual

In particular:

* Consultant does NOT mean Manual.
* Organisation does NOT mean Automatic.
* CarbonTally Internal does NOT mean Automatic.
* Processing Entity is additional controlled manual-processing capacity, but manual processing is NOT exclusively performed by Processing Entities.

## Input types

The processing model supports, as evidenced by the reconciliation:

* PDF
* CSV
* XLS/XLSX
* images

Input type is independent of actor, processing mode and workflow state.

## Automatic → manual fallback

The original model supports:

```text id="m0iy84"
Input
  ↓
Automatic extraction / mapping
  ↓
Confidence / validation gates
  ↓
Success → continue
  ↓
Failure / unresolved data
  ↓
Human correction / extraction / mapping
  ↓
Continue processing
```

This is an existing foundational CarbonTally workflow pattern.

It is NOT a new Phase-6 feature.

## Processing origin

`processing_origin` is NOT actor identity.

`processing_origin` is NOT processing mode.

It identifies the manual-processing capacity/control path:

* CarbonTally Internal
* Processing Entity

Its existing CHECK constraint, immutability and routing semantics remain unchanged.
