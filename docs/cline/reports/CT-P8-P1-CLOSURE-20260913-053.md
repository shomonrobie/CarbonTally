## 4. Residual (explicit — this is why the gate stays closed)

**Real institutional documents were not available in this environment**, so the shadow evidence in §3 is measured on fixture/representative documents only. Per `P1-D1`, **customer-visible behaviour may change only after shadow evidence demonstrates the classifier is sufficiently selective** — therefore:

* the shipped default remains **`shadow`** (`CARBONTALLY_P1_EXTRACTION_SHAPE` unset);
* `enabled` is implemented and tested but **not** switched on;
* the remaining gate step is a **shadow run over a real (non-production) institutional document set**, after which the PO/verifier may enable the shape for new uploads.

This is a deliberate, PO-ratified stop condition, not an omission.
