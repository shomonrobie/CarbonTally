# Overview

CarbonTally is an AI-powered carbon data preparation and emissions calculation platform designed to transform messy business data into audit-ready carbon reports.

Unlike traditional carbon accounting software, CarbonTally focuses on solving the biggest challenge in sustainability reporting:

> **Collecting, extracting, cleaning, validating and mapping messy operational data before calculating emissions.**

# Unique Value Proposition

CarbonTally is not simply a carbon calculator.

It is an **AI-powered Carbon Data Preparation Platform** that enables organizations to:

- Ingest messy operational data from CSVs, PDFs, and images.
- Extract structured information using AI and OCR.
- Map records against curated DEFRA emission factors.
- Correct low-confidence mappings through an interactive validation interface.
- Support human-in-the-loop quality assurance for audit-ready accuracy.
- Calculate Scope 1, Scope 2, and Scope 3 emissions.
- Export clean, validated datasets for reporting and compliance.

This workflow bridges the gap between unstructured operational documents and reliable carbon accounting, reducing manual effort while improving data quality and audit readiness.
