Why I strongly recommend no client deletion
CarbonTally is ultimately an evidence and calculation chain, not merely a document repository.
We want:
Source → extraction → validation → mapping → calculation → review → approval → report → audit history

A client should be able to say:
“This electricity figure is wrong.”

They should not be able to silently erase the underlying evidence.
Instead:
Client reports/corrects → consultant reviews → authorised operator changes data → audit trail records the change.

That's much safer for auditability and assurance.

E. Client user role authority — DECISION: C, with a security refinement

C — dual authority

Consultant

Client Organisation
